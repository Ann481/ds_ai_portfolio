    Find Friends – Project Overview

    🤝 Find Friends

    An application for finding like-minded people with shared interests

    📌 About the Project

    Find Friends is an application built for participants of the course. Its main goal is to connect people and help them find peers with similar profiles and passions.

    ⚙️ How It Works

    The matching and analysis process consists of a few simple steps[cite: 1]:

    • User Input: Users provide basic details about themselves, including age, education level, favorite animals, preferred location, and gender.
    • Clustering Algorithm: A machine learning clustering algorithm processes the inputs and assigns the user to a cluster of people with the most similar profile.
    • LLM Description: A unique summary description for each identified cluster is automatically generated by a Large Language Model (LLM).
    • Data Visualization: Interactive charts display attribute distributions for each group (e.g., age ranges, gender, or pet preferences).

    🚀 Interface Features

    📝 Profile Form

    An intuitive sidebar allowing users to define their traits and preferences easily.

    🤖 Automated AI Descriptions

    Unique group profiles and summaries generated dynamically by AI.

    📊 Data Analytics & Charts

    Visual representation of age, gender, and hobby distributions among group members.
